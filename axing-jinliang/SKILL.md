# 阿星进量

## 目标

完成阿星项目从飞策系统导出数据到最终进量文件的处理。原始下载文件必须保留，脚本只生成新的结果文件。

## 前置条件

- 使用已登录的老师助理飞策系统网页。
- 当前日期按 Asia/Shanghai 计算；“本周周一到今日”使用运行当天的周一 00:00 到当天结束时间。
- 需要得到两份 Excel 文件：`线索管理明细表*.xlsx` 和 `店铺订单*.xlsx`。
- 如果下载目录存在多个候选文件，按导出完成时间选择最新的一份；无法唯一判断时先询问用户。

## 浏览器导出流程

使用浏览器控制能力操作已登录页面。每次点击、选择和下载前，先根据当前页面的可见状态确认控件，不要凭猜测使用选择器。

### 低耗操作规则

- 页面切换后只读取一次完整页面快照，用它确认菜单、筛选器和按钮；后续点击优先复用已确认的可见文本或局部定位，不要反复读取包含整张表格的快照。
- 点击“查询”后只等待加载指示消失、结果数量出现或结果容器稳定，不读取整张结果表。列表等待设置 30 秒上限，超时就报告页面状态。
- 日期选择器只选择当前月份且在可见范围内的日期单元格；相邻月份补位日期即使文字相同也不能点击。日期范围固定为本周一 00:00 到今日结束。
- 每个导出任务只提交一次；点击“明文导出”后最多等待 60 秒。不要因为等待慢而再次提交，避免产生重复导出文件。
- 消息中心使用老师助理左侧的顶部红点消息入口（通常是 `span.ant-badge` 一类的未读消息控件）。不要把带 `title="客户端下载"` 的下载图标当成消息入口。
- 进入消息中心后先切到“下载 (N)”标签，再按导出完成时间从新到旧定位记录；只处理本次提交产生的最新记录，并点击一次“下载数据”。
- 如果浏览器下载列表没有落盘文件，优先从同一条消息的“下载数据”链接取得 `href`，直接保存到项目 `data` 目录；不要重新提交导出。保存完成后确认文件名和大小，再交给脚本处理。

### 导出线索管理明细表

1. 打开老师助理的飞策系统，进入“销售”。
2. 在左侧进入“线索管理”，点击“更多”。
3. 清空“取消手机尾数”下的时间范围。
4. 在“表单填写时间”范围中选择本周周一到今日。
5. 在“请选择分配部门”中选择“昕姐前端”，点击“查询”。
6. 等待列表加载完成，点击设置图标旁的下载图标，再选择“明文导出”。
7. 等待导出完成。打开老师助理左侧顶部红点消息入口，切到“下载 (N)”标签，点击最新的“线索管理明细表+日期.xlsx 已导出”记录，再点击“下载数据”。
8. 记录实际下载路径，不要改动原文件。

### 导出店铺订单信息

1. 回到飞策系统，进入“推广”→“店铺管理”，点击“更多”。
2. 将“订单创建开始时间”到“订单创建结束时间”设置为本周周一到今日，点击“查询”。
3. 等待列表加载完成，点击设置图标旁的下载图标，再选择“明文导出”。
4. 等待导出完成，打开左侧顶部红点消息入口，切到“下载 (N)”标签，找到最新的“店铺订单-日期已导出完成”记录，点击“下载数据”。
5. 记录实际下载路径，不要改动原文件。

如果导出没有在 60 秒内完成、消息记录名称不匹配或下载失败，停止后报告当前页面状态，不要重复提交导出任务造成重复文件。

## Excel 自动处理

调用 `scripts/axing_jinliang.py`。如果两份文件在同一下载目录，优先让脚本按修改时间自动选最新文件：

```text
python scripts/axing_jinliang.py --download-dir "项目/data" --output-dir "项目/outputs"
```

也可以显式传入文件：

```text
python scripts/axing_jinliang.py --clue "线索管理明细表.xlsx" --orders "店铺订单.xlsx" --output-dir "输出目录"
```

`--download-dir` 会忽略 `.crdownload`、已有“阿星进量”结果文件，并分别从 `线索管理明细表*.xlsx` 与 `店铺订单*.xlsx` 中选择最新文件；若文件名或时间异常，改用显式路径并先报告。

脚本执行以下处理：

1. 读取订单表的“联系方式”“订单状态”“商品名称”列，排除“订单已取消”和“售后取消”；手机号和联系方式统一转换为可比对的数字字符串。
2. 读取线索表的“手机号码”“表单填写时间”“微信号”列，并按“表单填写时间”升序排列。
3. 按手机号码匹配订单表中的“商品名称”，将结果写入线索表的“微信号”列。
4. 删除没有匹配结果的记录；如果存在“QQ号”列，则从最终输出中删除该列。
5. 输出 `线索管理明细表_阿星进量_YYYY-MM-DD.xlsx`，不覆盖任何原始下载文件。

脚本会校验所需列是否存在，并返回匹配成功数、未匹配数、排除取消订单数、重复订单手机号数、跳过的空行数、删除QQ号列状态和输出路径。匹配逻辑等价于以手机号码为键执行 XLOOKUP，但直接写入结果值，避免输出 `#N/A` 公式；重复手机号保留订单表中首次出现的有效订单，和原 XLOOKUP 的首次匹配语义一致。

## 完成检查

- 确认输出文件存在且可以打开。
- 报告线索总数、匹配成功数、未匹配数和输出文件路径。
- 如果输出为空、必要列缺失或匹配数量明显异常，保留原文件并先报告，不要覆盖或删除源文件。
