# 直播数据指标口径与字段说明

## 使用原则

指标先引用当前分析工具的返回值，再进行解释。不要根据历史报告或常见行业经验改写当前指标。当前代码只根据输入文件中实际存在的字段计算指标，缺少字段时应返回缺失或数据不完整，而不是补猜数值。

## 当前程序口径

当前程序对核心漏斗比例默认使用输入文件总记录数作为分母。输入文件通常代表预约用户或线索用户，因此报告中应将该分母称为“当前文件记录数”，除非业务已经确认它就是预约人数。

核心指标包括：

| 指标 | 当前计算含义 | 主要字段 |
| --- | --- | --- |
| 到课率 | 是否到课为真的记录数 / 总记录数 | `是否到课` |
| 完课率 | 是否完课为真的记录数 / 总记录数 | `是否完课` |
| 商品访问率 | 是否访问课程商品为真的记录数 / 总记录数 | `是否访问课程商品` |
| 领券率 | 是否领取优惠券为真的记录数 / 总记录数 | `是否领取优惠券` |
| 支付发起率 | 是否发起支付为真的记录数 / 总记录数 | `是否发起支付` |
| 购买率 | 是否购买课程为真的记录数 / 总记录数 | `是否购买课程` |

上述口径不等同于“上一步到下一步”的条件转化率。如果需要计算访问商品用户中的领券率、支付用户中的购买完成率等条件转化率，应新增独立指标，不能直接重新解释现有字段。

## 必需字段与可选字段

- 必需字段：`是否到课`、`是否完课`。
- 漏斗可选字段：`是否访问课程商品`、`是否领取优惠券`、`是否发起支付`、`是否购买课程`、`是否观看回放`。
- 观看时长字段：`直播观看时长`、`回放观看时长`。
- 维度字段：`邀请人`、`线索渠道`、`直播场次`、`直播标题`。
- 时间字段：`预约时间`。

## 数据质量规则

- “是/否”“yes/no”“1/0”等布尔值会被标准化。
- 无法识别的布尔值会被记录为未知，并进入数据质量警告。
- 缺少必需字段时，分析应直接失败并提示缺失列。
- 缺少可选字段时，不应虚构对应指标或维度。
- 观看时长会转换为秒，并在有到课用户和时长字段时计算平均观看时长和中位观看时长。
- 计算前应关注重复记录、取消订单、退款订单和用户去重口径；当前程序不会自动替业务判断这些规则。
