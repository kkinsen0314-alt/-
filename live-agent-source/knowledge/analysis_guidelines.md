# 直播运营分析总原则

分析时优先确认样本量、数据质量和指标口径。完课率、到课率和购买率需要引用工具返回的当前数据；历史报告只能用于趋势参考。

证据优先级依次为：当前工具结果、当前文件的数据质量提示、已确认的业务口径、历史报告和通用运营经验。历史报告不能替代当前数据，通用经验不能被写成当前数据已经证明的因果结论。

当完课率明显偏低时，优先检查中位观看时长、平均观看时长、直播中段流失和内容节奏；当访问商品后没有领券或支付时，优先检查商品曝光、优惠钩子、行动号召和人工跟进。若文件中没有对应字段，应明确标记为“待验证假设”。
