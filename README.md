# Zihan 的 AI 个人作品集

## 1. 直播数据智能分析 Agent

**项目定位**  
面向直播运营团队的 AI 数据分析助手，帮助用户快速完成直播数据分析并获得可执行的运营建议。

**核心功能**  
- 支持上传 CSV 或 Excel 格式的直播数据
- 自动完成直播漏斗、邀请人和渠道分析
- 结合运营知识库与历史分析报告定位问题
- 输出结构化分析结果和优化建议

**技术思路**  
采用“确定性计算 + 大模型分析”的协作模式：

- Python 负责数据清洗、指标计算、阈值判断和异常识别
- LLM 负责多轮工具调用、问题归因和建议生成
- 通过工具注册、结构化输出和知识库检索提升分析稳定性

## 2. 阿星进量 Skill

**项目定位**  
一套面向飞策系统的个人数据处理 Skill，用于自动化完成线索与订单数据的整理和进量文件生成。

**核心功能**  
- 自动导出线索与订单数据
- 清洗取消订单及无效数据
- 通过手机号完成线索与订单匹配
- 自动剔除不符合条件的数据
- 生成标准化进量 Excel 文件

**解决的问题**  
将原本重复的人工导出、筛选、匹配和整理流程整合为一套可重复执行的数据处理流程，提高日常数据处理效率和结果一致性。
